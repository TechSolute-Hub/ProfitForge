# ProfitForge

## Adaptive Intelligent Market Research Bot

ProfitForge is being rebuilt as an evidence-first research and decision-support application covering stocks, forex and crypto.

### Implemented foundation
- FastAPI backend
- Server-side Twelve Data provider abstraction
- Canonical market snapshot with source, timestamp and status
- OHLCV validation
- Deterministic EMA/RSI/ATR, trend, momentum, structure and regime analysis
- Explainable score, confidence, invalidation and alternative scenario
- React/Vite research dashboard
- Backend/frontend CI
- Environment templates and architecture documentation

### Next implementation layers
Multi-timeframe confluence, provider fallbacks, caching/persistence, news/sentiment, economic calendar, adaptive weight versioning, signal outcome tracking, Supabase-backed user data, alerts, richer charts and LLM synthesis will be added without bypassing canonical data validation.
